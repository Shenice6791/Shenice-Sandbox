## Page header description

In the page header, the software summarises the number of records that are:

* All active
* Not sent
* Submitted
* Not quoted
* Cancelled

{{< image text="Image showing of UI" src="Imagename.png">}}

Add description of functions to replace this placeholder description. The header options allow you to customize which fields are displayed in your user records view. You can toggle columns on or off to show information such as full name, email address, phone number, registration date, account status, and user role. Additionally, you can rearrange the order of columns by dragging and dropping header titles, sort records by clicking on any column header, and adjust column widths to optimize your workspace. The system remembers your header preferences across sessions, ensuring a consistent experience each time you access the records. Advanced filtering options are available through the header dropdown menus, enabling you to quickly narrow down records based on specific criteria within each field.
